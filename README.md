# Task Money UI Phase 11

Adds the remaining user and admin UI pages to the Phase 10 dashboard shell.

## Added routes

- /my-tasks
- /earnings
- /referrals
- /support/new
- /admin
- /admin/tasks
- /admin/proofs
- /admin/finance/withdrawals
- /tasks/[id]

## Install

Copy these folders into your project root after Phase 10.

```powershell
npm install react-icons
npm run build
npm run dev
```

Then deploy:

```powershell
git add .
git commit -m "Add remaining Task Money dashboard pages"
git push origin main
```
